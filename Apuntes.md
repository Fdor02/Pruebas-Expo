Este es un repositorio de preubas, para hacer cualquier prueba modificacion o intento "sucio" sobre expo o cualquier cosa relacionada, por lo que es probable que las cosas no hagan sentido.

En este archivo ire anotando mis apuntes de lo aprendido para futuras consultas y referencias.

1- Es necesario crear la app (npx create-expo-app Pruebas-Expo) ademas de instalar todas las dependencias, al momento de iniciar la app obtenia errores sobre el sdk y funcionamiento a pesar de que funcionaba el comando npx expo start
2- Atento con las direcciones de directorio. Al crear la app con expo desde el terminal de vscode SE CREA el directorio, dentro de una carpeta con todos sus elementos, pero puede traer problemas. Cree una app con nombres similares y duplique los elementos.
